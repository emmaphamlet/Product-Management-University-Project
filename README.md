# Product Management University Project

This repository contains documentation created for an INFO 380 product management project at the University of Washington. The project explores the design and planning of a system to improve student course registration workflows.

## Overview

The project includes research, stakeholder analysis, requirements definition, workflow diagrams, and product planning artifacts developed collaboratively throughout the course.

The documentation has been converted from an Azure DevOps wiki into a GitHub Pages site for portfolio purposes.

🔗 View the documentation site:
